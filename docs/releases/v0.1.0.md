# RetryShield v0.1.0

The first public preview of RetryShield turns retry safety into a deployable gateway rather than application-specific glue.

## Highlights

- Atomically claims idempotency keys in PostgreSQL before forwarding mutations.
- Replays the exact stored response for identical completed requests.
- Rejects key reuse with a different request fingerprint.
- Stops automatic retries when an upstream outcome is indeterminate.
- Provides an authenticated React operations console for investigation and resolution.
- Includes optional Redis acceleration, AES-GCM payload protection, OpenTelemetry/Prometheus metrics, and Grafana dashboards.
- Ships as a local Docker Compose stack with a payment demo, chaos scenarios, and a 50-client concurrency exercise.

## Important

This is a `0.x` preview intended for evaluation and contribution. Review the documented [guarantees and limits](https://github.com/Rezakarimzadeh98/retryshield/blob/v0.1.0/docs/guarantees.md), replace every development secret, and validate backup/recovery procedures before production use.

Container images are published to GitHub Container Registry by the release workflow.
