# RetryShield v0.2.0

This release turns the first public preview into a verifiable deployment path.

## Highlights

- Proves PostgreSQL atomic claiming with 50 concurrent Testcontainers clients.
- Runs a full Compose smoke test that verifies one upstream payment and one exact replay.
- Applies versioned, serialized PostgreSQL schema migrations with future-version protection.
- Supports a configurable real upstream and a demo-free production Compose overlay.
- Makes the operations dashboard work on remote hosts through a same-origin API proxy.
- Ships Prometheus alert rules and a detailed client key/retry contract.
- Gates every container release on backend, frontend, architecture, PostgreSQL, Playwright, and full-stack checks.
- Publishes multi-architecture SBOM/provenance, GitHub build attestations, and blocks images with known fixable high/critical vulnerabilities.

## Run the released stack

```bash
git clone https://github.com/Rezakarimzadeh98/retryshield.git
cd retryshield
cp deploy/.env.example deploy/.env
docker compose --env-file deploy/.env \
  --profile demo -f deploy/compose.yml -f deploy/compose.release.yml up -d --wait
```

Review the [guarantees](https://github.com/Rezakarimzadeh98/retryshield/blob/v0.2.0/docs/guarantees.md), [client contract](https://github.com/Rezakarimzadeh98/retryshield/blob/v0.2.0/docs/client-integration.md), and [operations guide](https://github.com/Rezakarimzadeh98/retryshield/blob/v0.2.0/docs/operations.md) before production evaluation.
